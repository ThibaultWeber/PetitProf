🧮 Calculatrice Scientifique

Utilisez cette calculatrice pour tous vos calculs mathématiques avec fonctions trigonométriques, logarithmes et notation scientifique.

0

💡 Guide d'utilisation

🔢 Fonctions de base

  • Chiffres 0-9 : Saisie des nombres
  • Opérateurs : +, -, ×, ÷ pour les opérations de base
  • Puissance : ^ pour élever à une puissance
  • Virgule : . pour les nombres décimaux

📐 Fonctions trigonométriques

  • sin, cos, tan : Fonctions trigonométriques de base
  • Arcsin, Arccos, Arctan : Fonctions trigonométriques inverses
  • sh, ch, th : Fonctions hyperboliques
  • Ash, Ach, Ath : Fonctions hyperboliques inverses

📊 Fonctions avancées

  • ln : Logarithme népérien (base e)
  • log₁₀ : Logarithme en base 10
  • e^x : Exponentielle
  • ×10^x : Notation scientifique

🎛️ Contrôles

  • Maths : Mode écriture mathématique (orange quand activé)
  • Sci : Mode notation scientifique (orange quand activé)
  • ⌫ : Supprimer le dernier caractère
  • C : Effacer tout
  • OFF : Réinitialiser la calculatrice
